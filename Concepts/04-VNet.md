# Azure Virtual Network (VNet)

## Definition

An Azure Virtual Network (VNet) is a logically isolated network within Azure that enables Azure resources to communicate securely.

---

## Purpose

- Private networking
- Resource communication
- IP address management
- Security isolation

---

## Project Example

```text
vnet-neeraj-storage01
```

Address Space:

```text
10.10.0.0/16
```

---

## Structure

```text
VNet
|
|-- snet-app
|
|-- snet-privateendpoint
```

---

## Key Learning

A VNet acts as the foundation for all private communication within Azure.
