# Azure Blob Storage

## Definition

Blob Storage is Azure's object storage service used to store files.

---

## Common Use Cases

- Images
- Videos
- Documents
- Logs
- Backups

---

## Hierarchy

```text
Storage Account
|
Container
|
Blob
```

---

## Project Example

```text
storage01finance
|
|-- backups
|
|-- logs
|
|-- documents
```

---

## Example Blob

```text
backup.txt

app.log

sample.pdf
```

---

## Key Learning

Blob Storage is primarily used for storing unstructured data such as files and backups.
