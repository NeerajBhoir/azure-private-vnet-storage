# Azure Storage Account

## Definition

A Storage Account is the parent Azure resource that provides storage services.

---

## Services Inside a Storage Account

```text
Blob Storage
File Shares
Queues
Tables
```

---

## Why Do We Need a Storage Account?

Storage services cannot exist independently.

Everything belongs to a Storage Account.

---

## Project Example

```text
storage01finance
```

---

## Responsibilities

- Data Storage
- Security
- Access Control
- Encryption
- Billing

---

## Key Learning

The Storage Account acts as the management boundary for Azure Storage.
